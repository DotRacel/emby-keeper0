# 安装指南

## 欢迎使用

🌈 欢迎您使用 Embykeeper0!

::: tip 首先
本 fork 仅提供 Docker 部署. 请尽可能使用 [**📦 本地部署**](#本地部署) 以保证稳定性.
如果您没有一台长时间运行的服务器, 可访问[相关文章](https://blog.zetx.tech/2024/05/19/vps-beginner-1)(第三方外部资源), 获取免费使用的 VPS 服务器.
:::

## 本地部署

本地部署需要一台长时间运行的计算机或服务器. 当前维护版本推荐使用容器部署:

- [🐳 Docker 部署](/guide/Linux-Docker-部署) **(推荐)**
- [🐳 Docker Compose 部署](/guide/Linux-Docker-Compose-部署)

请参照对应的安装教程进行安装, 若您需要更精细的控制, 请参考 [🔧 配置文件](/guide/配置文件) 和 [⌨️ 命令行参数](/guide/命令行参数).
