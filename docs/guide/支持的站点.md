# 支持的站点

## 支持 Emby 保活的站点:

::: tip 所有!

只要您的影视服务器是 Emby 服务器 或 Jellyfin 服务器, 就可以保活.

:::

## 支持机器人签到的站点:

本工具已支持 100+ 个 Telegram 签到站点. 由于站点列表随版本持续更新, 完整且最新的列表请查看源码目录 [`embykeeper/telegram/checkiner/`](https://github.com/DotRacel/emby-keeper0/tree/main/embykeeper/telegram/checkiner).

站点的启用与禁用通过 [**🔧 配置文件**](https://dotracel.github.io/emby-keeper0/guide/配置文件#site-子项) 的 `site` 子项控制. 部分仍在测试中或已停用的站点**默认禁用**, 您可以按需启用.

::: tip 提示
以上站点名均可以被用于配置文件, 站点名与机器人的用户名不一样!

例如 `飞跃` 的站点名为 `feiyue`.
:::
