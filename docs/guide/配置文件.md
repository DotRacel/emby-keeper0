# 配置指南

Embykeeper 使用 `toml` 格式配置文件, 默认为 `config.toml`.

首次运行时会生成一个模板配置文件. 您也可以运行:

```bash
embykeeper --example-config
```

<!--@include: ./_简要配置.md-->

## 顶级项目

| 设置项 | 值类型 | 简介 | 默认值 |
| ----- | ----- | ---- | ------ |
| `mongodb` | `str` | MongoDB 连接字符串 | (不使用) |
| `basedir` | `str` | 基础目录路径 | (使用用户目录) |
| `proxy` | `dict` | 代理设置子项 | |
| `emby` | `dict` | Emby / Jellyfin 保活配置子项 | |
| `subsonic` | `dict` | Subsonic / Navidrome 保活配置子项 | |
| `checkiner` | `dict` | Telegram 机器人签到配置子项 | |
| `telegram` | `dict` | Telegram 账号子项 | |
| `notifier` | `dict`/`bool` | 通知设置子项 | |
| `site` | `dict` | 签到站点配置子项 | |

::: info 旧版本
一些旧版本配置项仍然支持, 但建议使用新的配置方式：

- `time` -> `checkiner.time_range`
- `timeout` -> `checkiner.timeout`
- `retries` -> `checkiner.retries`
- `concurrent` -> `checkiner.concurrency`
- `random` -> `checkiner.random_start`
- `watch_concurrent` -> `emby.concurrency`
- `listen_concurrent` -> `subsonic.concurrency`
- `watchtime` -> `emby.time_range`
- `listentime` -> `subsonic.time_range`
- `interval` -> `emby.interval_days`/`subsonic.interval_days`
- `notify_immediately` -> `notifier.immediately`
- `service` -> `site`
:::

## `proxy` 子项

该子项用于配置连接 Telegram、Emby 和 Subsonic 服务器的代理. 默认不使用代理.

| 设置项 | 值类型 | 简介 | 默认值 |
| ----- | ----- | ---- | ----- |
| `hostname` | `str` | 代理服务器地址 | |
| `port` | `int` | 代理端口号 | |
| `scheme` | `str` | 代理协议, 可以为 `socks5` 或 `http` | |
| `username` | `str` | 代理用户名 | |
| `password` | `str` | 代理密码 | |

```toml
[proxy]
hostname = "127.0.0.1"
port = 1080
scheme = "socks5"
```

## `telegram.account` 子项

| 设置项 | 值类型 | 简介 | 默认值 |
| ----- | ----- | ---- | ------ |
| `phone` | `str` | 带国家区号的账户手机号 | |
| `checkiner` | `bool` | 启用机器人签到功能 | `true` |
| `site` | `dict` | 账号单独的 `site` 配置 | |
| `checkiner_config` | `dict` | 账号单独的 `checkiner` 配置 | |
| `api_id` | `str` | Telegram Application ID | |
| `api_hash` | `str` | Telegram Application Hash | |
| `enabled` | `bool` | 是否启用该账号 | `true` |

```toml
[[telegram.account]]
phone = "+8613901234567"
checkiner = true
```

## `checkiner` 子项

| 设置项 | 值类型 | 简介 | 默认值 |
| ----- | ----- | ---- | ------ |
| `time_range` | `str` | 签到时间或时间范围 | `"<11:00AM,11:00PM>"` |
| `timeout` | `int` | 单站点签到超时 (秒) | `120` |
| `retries` | `int` | 签到错误重试次数 | `4` |
| `concurrency` | `int` | 最大并发站点数 | `1` |
| `random_start` | `int` | 各站点随机错开启动时间 (分钟) | `60` |
| `interval_days` | `int`/`str` | 签到间隔天数 | `1` |

```toml
[checkiner]
time_range = "<11:00AM,2:00PM>"
timeout = 120
retries = 4
concurrency = 1
random_start = 60
```

### 站点独立时间范围

```toml
[checkiner]
time_range = "<9:00AM,10:00AM>"

[checkiner.terminus]
time_range = "<11:00PM,11:59PM>"
interval_days = 2
```

## `emby` 子项

| 设置项 | 值类型 | 简介 | 默认值 |
| ----- | ----- | ---- | ------ |
| `time_range` | `str` | 保活开始时间或时间范围 | `"<11:00AM,11:00PM>"` |
| `interval_days` | `int`/`str` | 保活间隔天数或范围 | `"<7,12>"` |

### `emby.account` 子项

| 设置项 | 值类型 | 简介 | 默认值 |
| ----- | ----- | ---- | ------ |
| `url` | `str` | Emby / Jellyfin 服务器地址 | |
| `username` | `str` | 用户名 | |
| `password` | `str` | 密码 | |
| `name` | `str` | 显示名 | |
| `time` | `list` / `int` | 模拟观看时长 (秒) | `[300, 600]` |
| `allow_multiple` | `bool` | 允许播放多个视频直到达到时间要求 | `true` |
| `allow_stream` | `bool` | 允许模拟播放没有时长信息的视频 | `false` |
| `device` | `str` | 自定义设备名称 | |
| `client` | `str` | 自定义客户端名 | |
| `client_version` | `str` | 自定义客户端版本 | |
| `useragent` | `str` | 自定义用户代理 | |
| `device_id` | `str` | 自定义设备 ID | |
| `use_proxy` | `bool` | 是否使用代理 | `true` |
| `play_id` | `str` | 仅播放特定视频 ID | |
| `interval_days` | `int`/`str` | 账号特定保活间隔 | |
| `time_range` | `str` | 账号特定保活时间范围 | |

```toml

[[emby.account]]
url = "https://emby.example.com"
username = "user"
password = "pass"
time = [300, 600]
```

## `site` 子项

该子项用于配置 Telegram 机器人签到启用的站点.

| 设置项 | 值类型 | 简介 | 默认值 |
| ----- | ----- | ---- | ------ |
| `checkiner` | `list` | 启用的签到站点 | 当前默认启用站点 |

```toml
[site]
checkiner = ["cc", "nebula", "terminus"]
```

可以使用 `all` 表示全部, `sgk` 表示全部社工库签到器:

```toml
[site]
checkiner = ["all", "-sgk"]
```

也可以在默认站点配置上增加或删除部分站点:

```toml
[site]
checkiner = ["+cc", "-terminus"]
```

不同 Telegram 账号可以使用不同的站点配置:

```toml
[site]
checkiner = ["+cc"]

[[telegram.account]]
phone = "+86111111111111"

[telegram.account.site]
checkiner = ["all", "-sgk"]
```

## 自定义签到站点

<!-- #region checkiner-templ -->

如果您需要的签到站点尚未被支持, 且符合通用模板格式, 可以通过模板创建.

### `templ_a`

适用于按钮面板风格的签到机器人:

```toml
[site]
checkiner = ["templ_a<moumou_bot>"]

[checkiner.'templ_a<moumou_bot>']
name = "某某站点"
templ_panel_keywords = "用户面板"
bot_checkin_button = "签到"
```

### `templ_b`

适用于发送命令后等待文本或验证码回复的机器人:

```toml
[site]
checkiner = ["templ_b<moumou_bot>"]

[checkiner.'templ_b<moumou_bot>']
name = "某某站点"
bot_checkin_cmd = "/sign"
bot_success_keywords = "签到结果"
```

<!-- #endregion checkiner-templ -->

## `notifier` 子项

通知功能只保留本地可配置的 Apprise 推送, 不再依赖 Embykeeper 在线 Bot 服务.

| 设置项 | 值类型 | 简介 | 默认值 |
| ----- | ----- | ---- | ------ |
| `enabled` | `bool` | 启用日志推送 | `false` |
| `immediately` | `bool` | 是否立刻推送日志 | `false` |
| `once` | `bool` | 启动时立刻执行的一次任务是否推送 | `false` |
| `method` | `str` | 推送方式, 当前仅支持 `apprise` | `apprise` |
| `apprise_uri` | `str` | Apprise 推送地址 | |

```toml
[notifier]
enabled = true
method = "apprise"
apprise_uri = "bark://hostname/device_key"
```

更多支持的服务请参考 [Apprise 官方文档](https://github.com/caronc/apprise).
