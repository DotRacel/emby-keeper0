# 参与开发

## 提供信息以帮助开发新签到器

如果您希望 Embykeeper0 支持一个新的 Telegram 签到器, 请通过 [GitHub Issues](https://github.com/DotRacel/emby-keeper0/issues) 反馈.

对于邀请制或不便公开调试的站点, 可以记录目标机器人的交互日志:

```bash
embykeeper config.toml -D all@test_bot > log.json
```

Docker 版本:

```bash
docker run -v $(pwd)/embykeeper:/app --rm -it --net=host ghcr.io/dotracel/emby-keeper0 -D all@test_bot > log.json
```

保持程序运行后, 手动在 `test_bot` 完成一次成功签到, 再进行一次签到以显示“今日已签到”信息. 程序会记录该过程中的目标聊天消息并输出到 `log.json`.

::: tip 提示
其他聊天的消息不会被记录. 日志中的个人信息会被隐藏, 包括用户 ID 等. 如有疑虑请在发送前检查文件.
:::

## 本地开发

1. Fork 本仓库.
2. 通过 `git clone <forked repo>` 克隆到本地.
3. 创建开发环境:

```bash
make develop
```

常用命令:

```bash
make run
make debugpy
make lint
make test
```

修改完成后提交 Pull Request.

## 扩展签到器

签到器位于 `embykeeper/telegram/checkiner`.

最简单的签到器示例:

```python
from . import BotCheckin


class DummyCheckin(BotCheckin):
    name = "Dummy"
    bot_username = "dummy_bot"
    bot_captcha_len = 4
```

如需识别验证码后点击按钮, 可以使用 `AnswerBotCheckin`:

```python
from pyrogram.types import Message

from . import AnswerBotCheckin


class DummyCheckin(AnswerBotCheckin):
    name = "Dummy"
    bot_username = "dummy_bot"

    async def on_captcha(self, message: Message, captcha: str):
        for char in captcha:
            try:
                await self.message.click(char)
            except ValueError:
                self.log.info(f'未能找到对应 "{char}" 的按键, 正在重试.')
                await self.retry()
                break
```

更多可用字段请参考 `embykeeper/telegram/checkiner/_base.py`.

## 项目结构

```bash
embykeeper/
  emby/                 # Emby / Jellyfin 保活
  subsonic/             # Subsonic / Navidrome 保活
  telegram/
    checkin_main.py     # Telegram 签到计划管理
    checkiner/          # Telegram 签到器
    dynamic.py          # 动态站点加载
    pyrogram.py         # Pyrogram 修复与增强
    telethon.py         # Telethon 登录辅助
    session.py          # Telegram 客户端池
    debug.py            # 消息调试工具
    lock.py             # 签到器共享锁
  cli.py                # 命令行入口
  config.py             # 配置读取与示例生成
  schema.py             # 配置模型
  schedule.py           # 计划任务
  runinfo.py            # 运行状态记录
embykeeperweb/          # Web 控制台
tests/                  # 测试
docs/                   # 文档
```
