# 日志推送

计划任务运行过程中, 关键成功或失败信息可以通过 Apprise 推送给您.

本维护版本已经移除 Embykeeper 在线 Bot 推送服务, 因此日志推送不再依赖 Telegram Bot.

## 开启条件

在 [配置文件](/guide/配置文件#notifier-子项) 中启用 `notifier`, 并将推送方式设为 `apprise`:

```toml
[notifier]
enabled = true
method = "apprise"
apprise_uri = "bark://hostname/device_key"
```

::: tip 提示
启动后首次立刻执行的一次签到 / 保活默认不会发送日志. 如需推送, 请设置 `once = true`.
:::

## 推送方式

[Apprise](https://github.com/caronc/apprise) 支持 Bark、钉钉、微信、邮件等多种推送方式.

更多支持的服务请参考 [Apprise 官方文档](https://github.com/caronc/apprise).
